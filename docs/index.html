Indian Fake Data Generator

A generator for culturally accurate, statistically consistent mock Indian demographic profiles, backed by Census 2011 data. Two native implementations, identical features and CLI.

Get Started Try the Playground CLI Reference

Statistically consistent

Religion, caste, state, language, education and income are correlated. No Sikh named Mohammed Sharma from Mizoram.

Census 2011 backed

Hand-calibrated approximations from Census 2011, NFHS-5 and survey data, bundled in. No runtime downloads.

Whole families

Generate a full household from one seed: head, spouse, parents, children and siblings with consistent surnames and ages.

Seeded and reproducible

Seeds can be numbers or strings ('011'). Same seed, same person, every time.

Zero dependencies

Both packages are dependency-free. Node 18+ or Python 3.8+, works offline.

AI-training ready

Optional layers add credit scores, narratives (loan applications, Hinglish chats) and LLM agent personas.
