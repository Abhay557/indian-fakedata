Indian Fake Data Generator

A generator for culturally accurate, statistically consistent mock Indian demographic profiles, backed by Census 2011 data. Two native implementations, identical features and CLI.

Get Started Try the Playground CLI Reference

Statistically consistent

Religion, caste, state, language, education and income are correlated. No Sikh named Mohammed Sharma from Mizoram.

Census 2011 backed

Hand-calibrated approximations from Census 2011, NFHS-5 and survey data, bundled in. No runtime downloads.

Whole families

Generate a full household from one seed: head, spouse, parents, children and siblings with consistent surnames and ages.

Seeded and reproducible

Seeds can be numbers or strings ('011'). Same seed, same person, every time.

Zero dependencies

Both packages are dependency-free. Node 18+ or Python 3.8+, works offline.

AI-training ready

Optional layers add credit scores, narratives (loan applications, Hinglish chats) and LLM agent personas.

New in 2.0.9

  • Work history — employmentTimeline: chronological job spells with title, sector, tenure and wages.
  • Skills — skills: technical/soft lists, certifications, per-language speaking/reading/writing levels.
  • New narratives — resume and customer_support_chat.
  • Persona languages — english, hindi, hinglish (--persona-lang).
  • CLI shaping — --fields, --stats, --strip-pii, --mask-names, --validate.
  • Trust — versioned JSON Schema (schema/profile-2.0.9.json), validateProfile, stripPII.

New in 2.1.0

  • Native script — nativeScript: names and address in the mother-tongue script.
  • Map points — geo: approximate latitude/longitude, state-clamped.
  • Life events — lifeEvents: dated birth, marriage, children, moves and jobs.
  • Household money — householdEconomy: budget splits, loans with EMI, credit history.
  • Festivals — dated observances by religion and state, derived on demand for personas and chats.
  • Smarter jobs — occupation follows education; job titles match the field of study.
  • AI training data — buildSFTPairs, grounded buildQAPairs with citations, and the --eval quality score.

Install

pip install indian-fakedata              # Python 3.8+
npm install @abhay557/indian-fakedata    # Node.js 18+

Both packages are on PyPI and npm, version 2.1.0, with zero runtime dependencies.

Acceptable use

Synthetic data only. All identifiers (Aadhaar, PAN, voter ID, phone, email) are fabricated and exist in no government or commercial database. This library may not be used to create fake identity documents, bypass KYC/verification systems, run bots or fake personas that interact with real people, spread disinformation, or present generated profiles as real data about real individuals. You are responsible for how you deploy the output. Full policy in the repository README.
